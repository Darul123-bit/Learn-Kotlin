## Getting Started

### Prerequisites

* Java Development Kit (JDK 17 or higher)
* Kotlin Command Line Compiler (`kotlinc`) or an IDE (IntelliJ IDEA, Android Studio)

### Compilation & Execution

To compile and run any Kotlin file via CLI:

```bash
# Compile the Kotlin source file
kotlinc <path-to-folder>/main.kt -include-runtime -d main.jar

# Execute the generated JAR
java -jar main.jar
